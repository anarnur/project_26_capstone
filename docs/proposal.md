# Market Intelligence Agent — Project Proposal

## Проблема (одним предложением)

Маркетологи и продакт-менеджеры тратят часы на ручной мониторинг конкурентов,
собирая данные из десятков разрозненных источников, и всё равно получают неполную картину.

---

## Целевой пользователь

**Кто:** продакт-менеджер, маркетолог или основатель стартапа в B2B/SaaS.

**Как решает задачу сейчас (без продукта):**
- вручную гуглит новости о конкурентах раз в неделю,
- читает отзывы на G2/Trustpilot в браузере,
- собирает всё в Google Docs и пишет SWOT самостоятельно.

**Боль:** процесс занимает 3–5 часов, данные устаревают быстрее, чем успеваешь их обработать.

---

## Решение

Мультиагентная система (LangGraph + CrewAI-паттерн), которая по названию компании или
URL за 2–3 минуты выдаёт структурированный отчёт:

- краткое описание продукта и позиционирования,
- последние новости и события (финансирование, релизы, скандалы),
- анализ тональности отзывов с платформ,
- SWOT-анализ с конкретными инсайтами,
- PDF-отчёт, готовый к шерингу.

---

## Агентная архитектура

```
Orchestrator (LangGraph)
├── Researcher Agent   → WebScraperTool, NewsSearchTool
├── Reviews Agent      → ReviewsScraperTool (G2, Trustpilot, Reddit)
└── Analyst Agent      → SWOTGeneratorTool, ReportBuilderTool
```

Оркестратор сам решает:
- если сайт недоступен → переключиться на веб-поиск,
- если отзывов < 10 → расширить источники (App Store, Reddit),
- если новостей за месяц нет → расширить период до 3 месяцев.

---

## Кастомные инструменты (custom tools)

| Инструмент | Описание | Технология |
|---|---|---|
| `WebScraperTool` | Парсит сайт конкурента | BeautifulSoup + httpx |
| `NewsSearchTool` | Новости за N дней | NewsAPI / SerpAPI |
| `ReviewsScraperTool` | Отзывы G2, Trustpilot | кастомный парсер |
| `SWOTGeneratorTool` | Структурирует данные в SWOT | LLM + Pydantic |
| `ReportBuilderTool` | Генерирует PDF-отчёт | WeasyPrint |

---

## RAG-слой

- **Данные:** история прошлых анализов компаний (накапливается в БД).
- **Векторная БД:** Qdrant (hybrid search: dense + sparse).
- **Зачем:** агент может сравнить текущее состояние конкурента с данными 3-месячной давности.

## Стек

| Слой | Технология | Обоснование |

## Минимум 5 пользовательских кейсов для тестирования агента

1. "Проанализируй Notion" — крупный известный продукт, много данных.
2. "Проанализируй Linear" — нишевый SaaS, проверяем работу при малом числе отзывов.
3. "Сравни Figma и Sketch" — два конкурента, мультизапрос.
4. Несуществующая компания — проверяем fallback и обработку ошибок.
5. Компания без публичных отзывов — проверяем расширение источников.

---

## Как получить 90+ баллов

- LangGraph с циклом самокоррекции (Analyst критикует → Researcher докапывает).
- Hybrid search в Qdrant (dense + sparse + RRF re-ranking).
- Streaming end-to-end: шаги агента видны в реальном времени на фронте.
- Observability dashboard: число запросов, latency, стоимость токенов.
- Eval-набор: 20 тест-кейсов с эталонными SWOT-ответами, прогон через LangSmith.

---

## Известные ограничения

- Парсинг сайтов с JS-рендерингом требует Playwright (усложняет Docker-образ).
- Rate limits NewsAPI на бесплатном тарифе: 100 запросов/день.
- Качество SWOT зависит от количества доступных публичных данных о компании.
